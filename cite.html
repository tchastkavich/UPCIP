Interactivity

Home Page/Index

Clicking on the logo in the top menu will take you here
Clicking on the word ENGLISH underneath the menu (All Pages) will switch the language to the galactic standard language (It takes you to a second version of the page with a font that makes all text the language from Star Wars, Aurabesh)
Clicking on the 'About Us' button takes you to the About Page
Clicking on the 'Click Here!' button takes you to an Error Code 404 Page
Clicking on the 'Join The UPCIP Today!' button takes you to the Apply Page

About Page

Clicking on the logo on this page and all other pages but the Home Page (English) will do absolutely nothing
Clicking on the 'Star Map' button takes you to the Error Code 404 Page

Apply Page

You can and must fill out all those boxes and click all the checkboxes to click the button at the bottom of the page
Clicking on the 'Terms and Conditions' link takes you to the Error Code 404 Page because I didn't feel like doing a terms and conditions page

Page 4/After Apply Page

Clicking the 'Back to Home' button, of course, takes you back to the Home Page

The Aurabesh Versions

Clicking on the last word where the 'This Page Has Been Translated to ENGLISH' is, will take you back to the English version on all pages


Clicking on the logo on the Home Page doesn't do anything, as it taking you here only works on the English version

Other Various Information

On the Aurabesh version of the About Page, the name that is untranslatable on the English version, is translated due to the page being the alien language the name originates in


On the Aurabesh version of the Apply Page, the 'My Name is Not Mark' checkbox that exists in the English version is not present


On the Home Page (English), the first image has a filter, saturate
